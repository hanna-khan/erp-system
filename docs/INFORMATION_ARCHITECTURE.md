# Zendrock Textile ERP — Information Architecture

## Product
Multi-tenant SaaS ERP for textile manufacturing (Pakistan-first, industry-configurable).

## Tenant hierarchy
Zendrock Platform → Tenant → Company → Branches / Plants → Warehouses / Work Centers → Users

## Module map
1. Overview — Dashboard, Demo Workflows, Zendrock AI
2. Commercial — CRM, Sales
3. Product — Product Master, Color×Size Matrix, BOM, Process Templates, PLM
4. Supply Chain — Procurement, Inventory, Warehouse
5. Manufacturing — Production, Floor MES, Planning & MRP, Quality, Costing
6. Assets & Ops — Machines, Maintenance, Subcontracting, Dispatch, Assets
7. Enterprise — Finance, HR & Payroll, Reports, Notifications
8. System — Organization, Approvals, Workflow Builder, Admin, Settings, Super Admin

## End-to-end demos
- Garments: Customer → SO → BOM → MRP → PO → GRN → Production → QC → FG → Dispatch → Invoice → Payment
- Weaving: Yarn → Warping → Sizing → Weaving → Grey QC → Dyeing → FG → Delivery
- Dyeing: Batch → Recipe → Chemicals → Dye → Wash → Dry → Inspect → Rework/Approve

## Roles
Super Admin, Tenant Admin, CEO, Production Manager/Supervisor, QC, Procurement, Warehouse, Accountant, HR, Sales, Maintenance, Factory Worker

## Localization (Pakistan)
PKR, NTN, STRN, Jul–Jun fiscal year, configurable tax, local address formats
